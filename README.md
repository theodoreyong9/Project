# Projects

## Experiments toward an AI-native social coordination infrastructure

This repository gathers a set of independent but related experiments around a common question:

> **What would social coordination look like if humans and autonomous agents could create, represent, discover, execute and exchange value without requiring a single application or a single central authority?**

The projects are deliberately built as separate systems.

They are not modules of one monolithic platform.

They are experiments in **composable primitives, local agency, peer-to-peer coordination, semantic representation and independently evolving forms of value**.

---

## The projects

### Jobber — Personal Interoperable Agency

A local-first, peer-to-peer coordination layer for human opportunities.

Jobber explores what happens when identity, matching, research and communication remain close to the individual rather than being mediated by a central marketplace.

**Primitive:** personal agency.

---

### SGD — Semantic Graph Democracy

An AI-mediated semantic graph for representing collective perspectives, preferences and intentions.

Rather than reducing collective expression to binary votes, contributions become structured relations inside an evolving semantic graph.

**Primitive:** collective representation.

---

### YourMine — Permissionless Execution

A permissionless runtime where applications, interfaces and communities can be created, forked, modified and redistributed without a central application gatekeeper.

The important object is therefore not a canonical application.

It is the **runtime and the interfaces that allow different applications and communities to coexist**.

A fork is not necessarily a deviation from the system.

It can be another instance of it.

**Primitive:** permissionless execution.

---

### AIWA Chain — Partitioned Global Coordination

A protocol experiment for value progression and transaction validation across independently progressing domains.

AIWA explores whether value can continue to accrue locally without requiring a permanently synchronized global state.

A domain can progress according to its own sequential computation and later exchange verifiable information with other domains.

**Primitive:** locally progressing value.

---

### Smartank — Capability Discovery

A local-first AI-mediated discovery layer for navigating an expanding ecosystem of models and capabilities.

Instead of requiring users to know the structure of the ecosystem beforehand, Smartank explores whether natural-language intent can become a discovery interface.

**Primitive:** capability discovery.

---

## ARVT — the reflexive layer

Alongside these technical experiments is **ARVT — Autonomous Relation Value Theory**.

ARVT is not another application layer.

It is an attempt to articulate the economic and philosophical intuition that appears across the experiments:

> **Value can be understood as the residue of a relation whose cost is real and whose continuity remains sustainable.**

ARVT is deliberately implemented as well as written.

Its corpus evolves through sequential contributions from visitors. Contributions are composed into new textual residues and organized through a semantic graph.

The theory therefore operates on itself:

**a theory of relational value becomes a relational process for producing a living theory.**

## Protocol-first, not product-first

These projects are intentionally open to divergence.

The goal is not necessarily to make everyone use the same application.

A stronger form of interoperability is possible:

> **different implementations can participate in the same ecosystem as long as they preserve the interfaces and invariants that make coordination possible.**

This means that a fork can be a feature rather than a failure mode.

Someone may:

* fork Jobber and radically change its interface;
* replace its AI layer;
* implement the protocol in another language;
* build a different execution environment around the same primitives;
* create a new community around a modified implementation;
* or combine only a subset of the ideas with another system.

The ecosystem does not need to authorize every implementation.

**Compatibility is the recognition mechanism.**

If two implementations speak the same protocol, they can participate in the same coordination space without being the same product.

---

## From applications to primitives

The long-term direction is therefore not:

```text
one application
      ↓
one community
      ↓
one authority
```

but rather:

```text
          primitives
              │
      ┌───────┼────────┐
      │       │        │
      ▼       ▼        ▼
 implementations / forks / communities
      │       │        │
      └───────┼────────┘
              │
              ▼
       shared coordination
```

The objective is to make divergence composable.

A system should remain useful when:

* its implementation changes;
* its community changes;
* its interface changes;
* its agent changes;
* its economic context changes;
* or another implementation replaces it entirely.

---

## Why open source matters here

Open source is not only a distribution model for these projects.

It is part of the architecture.

Publishing the source allows the system to be:

**read → copied → modified → forked → independently operated → recombined.**

The creator therefore gives up control over the final form of the system in exchange for something potentially more powerful:

**the ability for the system to become larger than its original implementation.**

The interesting question is not:

> "How do we make everyone use this application?"

It is:

> **"What are the smallest useful primitives that allow independent actors to coordinate without requiring the same application?"**

---

## Current status

These repositories are experiments, not a claim that an AI-native society has already been solved.

Some components are prototypes.

Some are reference implementations.

Some are theoretical work expressed through software.

Their value is partly in making the assumptions explicit, testable and forkable.

The common direction is exploratory:

> **build coordination infrastructure that can survive divergence.**

THE ARCHITECTURE

From applications to primitives.

These projects are not designed as a single platform. They are experiments in building social coordination infrastructure that can survive divergence.

One ecosystem.

Different implementations, forks, communities, agents and interfaces can participate in the same coordination space without becoming the same product.

Forks are a feature.

An open system does not need to authorize every implementation. If the relevant interfaces and invariants remain compatible, independent implementations can coexist and evolve.

Coordination without a center.

The objective is not to make everyone use the same application. It is to discover the smallest useful primitives that allow independent actors to coordinate.

ARVT
Value can be understood as the residue of a relation whose cost is real and whose continuity remains sustainable.

ARVT is an attempt to articulate the relational value logic underlying these experiments — not as another application layer, but as a reflexive theory of what these systems are trying to build.

Five architectures
Personal agency → Collective representation → Permissionless execution → Value progression → Capability discovery
